# Project Overview

## AI Learning Companion for Vocational Training (FP)

This project aims to build an AI-powered learning companion designed for FP students and teachers.  
It leverages M365 Copilot, AI ERP, and Generative AI to simplify complex technical concepts, generate personalized learning resources, and support teachers with curriculum-aligned materials.

### Objectives
- Improve accessibility and understanding of technical FP content.
- Provide teachers with AI-generated didactic resources.
- Integrate M365 Copilot and AI ERP into real learning workflows.
- Create a scalable solution for FP programs (ASIR/DAM).

### Why this project?
FP students often struggle with abstract or highly technical concepts.  
Teachers need tools that save time and align with curriculum requirements.  
AI can bridge both gaps.
