# Microsoft Global Hackathon 2026 – Project Workspace

Welcome! This repository contains my work, notes, prototypes, and documentation for the Microsoft Global Hackathon 2026.  
As a Microsoft MVP in M365 & Business Applications, I focus on applying M365 Copilot, AI ERP, and Generative AI to build meaningful educational solutions.

Starting in September, I transition fully into the education sector, bringing AI-powered innovation, curriculum design, and FP expertise into real classroom environments. This Hackathon is an opportunity to collaborate globally and create tools that support learning and accessibility.

## Project Focus
AI Learning Companion for Vocational Training (FP)

This project aims to simplify complex technical content (Big Data, distributed systems, cybersecurity) and support teachers with curriculum-aligned tools powered by M365 Copilot, AI ERP, and Generative AI.

## Hackathon Goals
- Build an AI-driven educational solution with real classroom impact  
- Collaborate with Microsoft employees, MVPs, RDs, and product teams  
- Apply M365 Copilot and AI ERP to learning innovation  
- Contribute expertise in pedagogy, curriculum design, and narrative structure  
- Support teams through mentoring, ideation, and pitch development  

## Repository Structure
- `/docs` – Project documentation, notes, and design decisions  
- `/src` – Code, prototypes, and experiments  
- `/assets` – Images, diagrams, and visual materials  
- `/pitch` – Slides, narrative drafts, and presentation materials
